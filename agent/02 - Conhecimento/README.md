# 02 - Conhecimento

## 1. Objetivo

Esta pasta concentra todas as fontes utilizadas pelo agente durante o processo de geração de respostas.

A qualidade do agente depende diretamente da qualidade das informações armazenadas nesta pasta.

Documentos incorretos, conflitantes ou desatualizados podem gerar comportamentos inadequados, respostas inconsistentes e aumento do risco operacional.

---

## 3. Critérios e Regras para novas inclusão

Antes de adicionar uma nova fonte verificar:

### Governança

- Existe owner definido?
- Existe versão do documento?
- Existe data de atualização?

---

### Qualidade

- Documento está completo?
- Documento está atualizado?

---

### Consistência

- Existe informação conflitante?
- Existe conteúdo duplicado?
- Existe documentação mais recente?

---


## 4. Checklist de Revisão

Antes de promover um documento para produção validar:

- Fonte homologada.
- Owner definido.
- Sem informações conflitantes.
- Versão atualizada.
- Revisão realizada.
- Data de atualização registrada.

---

## 5. Boas Práticas

✅ Utilizar nomenclatura padronizada.

✅ Versionar documentos.

✅ Manter owner definido.

✅ Remover duplicidades.

✅ Registrar mudanças relevantes.

✅ Revisar periodicamente todas as fontes.
